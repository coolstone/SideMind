## 文章主张（归档摘要）

文章以长期个人订阅经历为背景，说明 SideMind 的起点不是反对订阅或单纯追求低价，而是希望重新获得对浏览器 AI 工作流的控制：模型能自己选、历史能自己保存、提示词能自己维护、外部工具能自己连接，并能定位失败发生的环节。

文章把产品原则落为三条：

1. **本地优先**：浏览器上下文、聊天、提示词、工件和偏好优先在用户侧保存。
2. **接口可换**：页面/选区/截图等上下文可以交给用户配置的 API、Ollama，或经人工确认交给正常的 ChatGPT 网页。
3. **数据可迁移**：聊天 Markdown、历史导入导出和完整 JSON 备份，使升级、换机和回滚不依赖某一个服务商。

文章的产品边界也很明确：SideMind 借鉴浏览器侧栏 AI 的顺手工作流，不读取 ChatGPT Cookie、不调用私有接口、不替用户自动发送网页消息；它服务个人真实发生的阅读、写作、检索和开发，而不是试图覆盖通用 AI 平台。
